# ovos-skill-waggle

Phone actions for [OpenVoiceOS](https://openvoiceos.org) over [HiveMind](https://github.com/JarbasHiveMind): "set a timer for 10 minutes", said to a phone, sets the timer on that phone. The hub turns requests into **Waggle** messages (generic Android intents and a few named queries), and the phone runs them only as far as rules its user sets on the phone allow. The phone client is [Wiggins](https://github.com/greennosedmule/wiggins).

- [WAGGLE.md](WAGGLE.md): the protocol, v1.
- [SPEC.md](SPEC.md): this package: the `waggle` library, the pipeline stage and the request handlers.

Status: **S2**. Alarms, timers and "show alarms" work; contacts, apps and calendar (S3) and the LLM persona's hand-off (S4) are next.

## Install on a hub

Needs ovos-core 2.x. Install the package into ovos-core's environment, which registers the `opm.pipeline` plugin `ovos-waggle-pipeline-plugin`, and add its stage to `intents.pipeline` in `mycroft.conf`, right after the converse stage:

```json
"pipeline": ["…", "ovos-converse-pipeline-plugin", "ovos-waggle-pipeline-plugin-high", "…"]
```

Each phone's HiveMind client must be allowed to send the Waggle message types:

```sh
hivemind-core allow-msg waggle.capabilities <id>
hivemind-core allow-msg waggle.intent.response <id>
hivemind-core allow-msg waggle.query.response <id>
```

The stage only answers phones that have announced Waggle capabilities, so other satellites keep using the hub's own skills. See SPEC.md "Hub setup".

## Develop

```sh
uv venv && uv pip install -e '.[test]'
.venv/bin/python -m pytest
```

`waggle-fake-hub` sends scripted Waggle requests to a phone through a hub, for testing phone clients.
